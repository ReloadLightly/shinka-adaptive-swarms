<DESCRIPTION>
The current policy relocates four particles and raises radius from 1.25 to 1.5 when relative fitness loss exceeds 0.1 and diameter is below twice the default radius. Its mean error, 3.88, exceeds the constant-four/radius-1.25 result of 3.76.
Keep four particles and replace those thresholds with smooth displacement-based adjustment between 1.125 and 1.375. This tests whether modest spatial adaptation improves recovery while limiting radius expansion. Improvement remains unmeasured.
</DESCRIPTION>

"""Joint relocation seed: the original corrected baseline response.
The adapter fixes memory reevaluation and retained velocities. It converts the
integer count to the unchanged simulator's fraction interface without rounding
ambiguity. The seed allocates every particle at the baseline radius multiplier.
"""
# EVOLVE-BLOCK-START
def choose_relocation(observation: dict) -> dict:
    """Relocate four particles with a bounded displacement-based radius.
    Non-relocated particles continue ordinary PSO motion. The fixed adapter
    reevaluates personal memories and retains velocities.
    """
    count = min(4, int(observation["swarm_size"]))
    displacement = max(
        0.0, float(observation["observed_best_displacement"])
    )
    default_radius = max(
        1e-12, float(observation["default_radius"])
    )
    u = displacement / default_radius
    # Equivalent to 1.25 + 0.125 * (u - 1) / (u + 1),
    # avoiding an infinity/infinity ratio for extreme inputs.
    radius_scale = 1.375 - 0.25 / (1.0 + u)
    return {"count": count, "radius_scale": radius_scale}
# EVOLVE-BLOCK-END
