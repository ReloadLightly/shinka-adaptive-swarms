validation/final separation, selection rules and primary intervals are unchanged.

the three native run identities, scientific sources, task sources, cases,
resolved engine settings and analysis. Each completed case is written before
progress advances. Terminal failed native proposals consume their original slot;
recovery never fills them with additional generations. The sequential supervisor
is `scripts/run_joint_searches.py`.

The complete engine resolution is
[`resolved_engine.json`](../configs/joint_relocation_v3/resolved_engine.json).

existing ChatGPT subscription. No internal reasoning-effort override is supplied;
the provider's effective default is not independently verified. The user's
requested supervising Astra/Ultra setting must not be relabeled as the setting
of those internal calls. Mutation-model selection is fixed, with no adaptive
ensemble or prompt co-evolution. Native retries, novelty fallback and meta
failure handling remain intact and are logged separately from success.

768-dimensional vectors with the pinned official quantized Jina code encoder.
The pre-search development calibration freezes the native judge trigger at
cosine similarity greater than **0.830958258366903**. Cosmetic and meaningful
examples overlap; this routes broadly to the judge, not to automatic rejection.
The model revision, dependency versions, service command, explicit long-input
windowing, original development failure and calibration evidence are documented
in [`local_embeddings_v3.md`](local_embeddings_v3.md).

supplies the declared constant radius to action-distribution summaries and the
joint sampler. That projection is algebraic metadata, not a claim that a second
simulation was executed. Distinct state-dependent programs are never aliased on
observed score equality. This clarifies telemetry interpretation without changing
the execution-equivalence rule.
