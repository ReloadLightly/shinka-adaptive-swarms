<DESCRIPTION>
Retain the current program’s four-particle, 1.5-radius response, but use the other parent’s three-particle, 1.625-radius response when the swarm is compact and fitness has deteriorated. This tests whether preserving two ordinary PSO moves helps recovery under that condition. The three-particle parent had lower worst-case error but higher mean error; improvement from this crossover remains unmeasured.
</DESCRIPTION>

"""Joint relocation seed: the original corrected baseline response.
The adapter fixes memory reevaluation and retained velocities. It converts the
integer count to the unchanged simulator's fraction interface without rounding
ambiguity. The seed allocates every particle at the baseline radius multiplier.
"""
# EVOLVE-BLOCK-START
def choose_relocation(observation: dict) -> dict:
    """Use partial relocation for compact swarms with substantial fitness loss."""
    count = 4
    radius_scale = 1.5
    if (
        observation["relative_fitness_drop"] > 0.1
        and observation["swarm_diameter"] <= 3.0 * observation["default_radius"]
    ):
        count = 3
        radius_scale = 1.625
    return {
        "count": min(count, int(observation["swarm_size"])),
        "radius_scale": radius_scale,
    }
# EVOLVE-BLOCK-END
