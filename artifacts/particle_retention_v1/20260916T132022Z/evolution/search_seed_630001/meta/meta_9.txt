# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Refine the speed coefficient around 0.5.** With `d = particle_features["distance_to_best_normalized"]` and `v = particle_features["speed_normalized"]`, try `1/(1 + d + w*v)` for `w` in `{0.25, 0.375, 0.625, 0.75}`, plus `w=0` as a distance-only variant. Reducing the coefficient from 1 to 0.5 produced the strongest observed improvement, making nearby weights the highest-priority mutations.
2. **Reduce the penalty only for unusually high speed.** Set `T = max(1e-12, swarm_features["mean_speed_normalized"])` and return `1/(1 + d + 0.5*min(v,T) + 0.25*max(0,v-T))`, also trying thresholds `0.5*T` and `2*T`. This extends the successful reduction in speed penalty while preserving linear distance and ordinary-speed penalties; the unsuccessful square-root variant changed both features simultaneously.
3. **Adapt the coefficient modestly to swarm geometry.** Define `D = swarm_features["diameter_normalized"]`, `V = swarm_features["mean_speed_normalized"]`, and `w = max(0.25, min(0.75, 0.5*((1+D)/(1+V))**p))` for `p` in `{-0.5, 0.5}`, then return `1/(1+d+w*v)`. This tests whether the successful tradeoff benefits from observable state dependence while keeping it near the winning coefficient; unlike common score scaling, it changes relative feature weights.
4. **Add a small directional correction to the winning cost.** Let `a = particle_features["velocity_alignment"]` and return `1/(1 + d + 0.5*v - b*a*min(d,v))` for `b` in `{0.05, 0.1, 0.2}`. This preserves proximity and speed preference while modestly favoring motion toward the refreshed best, testing a limited extension given that fuller trajectory models underperformed.
5. **Switch selectively between half-speed and random retention.** Return `0.0` for every particle when `swarm_features["relative_fitness_drop"] > t`, otherwise retain `1/(1+d+0.5*v)`, trying `t` in `{0.1, 0.25, 0.5}`. Constant scores invoke the existing random tie breaker, preserving continuous geometric ranking outside the gate. Random retention’s four shorter-period wins motivate this hybrid, but fitness drop remains an unproven switching signal and should not be treated as a proxy for change period.
