<DESCRIPTION>
Preserve full conversion on detected change, but inherit the two-particle follow-up only for the next update and only when the preceding update produced no shared-best improvement. The unconditional three-update extension worsened development error; this crossover tests whether one selective retry supports recovery with less disruption to ordinary PSO. Performance improvement remains untested.
</DESCRIPTION>

```python
"""Published MPSO 5+1 temporary-conversion schedule."""
# EVOLVE-BLOCK-START
def choose_temporary_quantum_count(observation) -> int:
    if observation["change_detected"]:
        return 5
    if (
        observation["has_detected_change"]
        and observation["updates_since_detected_change"] == 1
        and observation["recent_improvement"] <= 0.0
    ):
        return 2
    return 0
# EVOLVE-BLOCK-END
```
