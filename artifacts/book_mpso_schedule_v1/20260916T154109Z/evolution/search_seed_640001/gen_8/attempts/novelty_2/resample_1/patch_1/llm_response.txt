<DESCRIPTION>
Use observed change magnitude to control burst intensity: convert four neutrals when the absolute relative fitness change is at most 1%, otherwise five. Return zero between detections. The hypothesis is that retaining one ordinary PSO move after small changes preserves useful convergence while maintaining substantial exploration. The threshold is exploratory, not an estimate of environmental severity. Interface checks passed; improved optimizer performance remains unverified.
</DESCRIPTION>

"""Published MPSO 5+1 temporary-conversion schedule."""
# EVOLVE-BLOCK-START
def choose_temporary_quantum_count(observation) -> int:
    if not observation["change_detected"]:
        return 0
    if abs(observation["relative_fitness_drop"]) <= 0.01:
        return 4
    return 5
