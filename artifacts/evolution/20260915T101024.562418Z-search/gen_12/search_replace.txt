<DESCRIPTION>
Test whether small fitness drops conceal meaningful displacement when a swarm is tightly concentrated. Relative fitness loss need not measure how far a peak moved, so the current narrow response may leave compact swarms searching around an obsolete location.
For compact swarms, smoothly raise the minimum radius multiplier toward 2.0 and relocation fraction toward 0.60, preserving some positional anchors. The extra response vanishes when swarm diameter reaches twice the default radius. Stronger existing responses remain intact; memory reevaluation and velocity preservation continue.
The stronger prior program outperformed the conservative policy, while some cases retained substantial interval-end error. This motivates testing additional spatial recovery where existing coverage is weakest, but does not establish that insufficient relocation caused those errors. This proposal is untested.
</DESCRIPTION>
