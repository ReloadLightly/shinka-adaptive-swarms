<DESCRIPTION>
Retains the stronger five-particle default and requests four only when neutrals are compact, close to the refreshed best, moving slowly, and observed fitness has not deteriorated. This tests selective query savings while preserving five elsewhere. Static contract and immutable-input checks passed; performance improvement remains unmeasured.
</DESCRIPTION>

```python
"""Reconstructed MPSO 5+1: maintain five neutral particles."""
# EVOLVE-BLOCK-START
def choose_neutral_count(observation) -> int:
    radius = max(observation["default_radius"], 1e-12)
    if (
        observation["fitness_drop"] <= 0.0
        and observation["neutral_diameter"] <= 2.0 * radius
        and observation["mean_neutral_distance_to_best"] <= radius
        and observation["mean_neutral_speed"] <= radius
    ):
        return 4
    return 5
# EVOLVE-BLOCK-END
```
