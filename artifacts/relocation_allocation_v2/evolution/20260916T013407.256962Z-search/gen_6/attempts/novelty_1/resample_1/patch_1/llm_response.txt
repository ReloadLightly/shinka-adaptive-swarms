<DESCRIPTION>
Use recent improvement as a recovery credit: relocate two particles when that credit covers the observed fitness loss, otherwise three. This preserves more ordinary PSO motion when recovery appears adequate.
The previous rule frequently executed four relocations and worsened mean error from 3.36 to 3.81; case_006 also worsened interval-end error from 2.21 to 4.40. These observations motivate testing conservative allocation, but do not establish its benefit. This proposal is untested.
</DESCRIPTION>

"""Allocate relocation using observed fitness loss and recovery progress.
The fixed adapter controls radius, memory, velocity, integer validation and
count-to-fraction conversion. The numerical simulator is outside this program.
"""
# EVOLVE-BLOCK-START
def choose_relocation_count(observation: dict) -> int:
    """Preserve more ordinary PSO motion when progress covers fitness loss."""
    swarm_size = int(observation["swarm_size"])
    if swarm_size <= 0:
        return 0
    loss = max(0.0, float(observation["fitness_drop"]))
    recovery_credit = max(0.0, float(observation["recent_improvement"]))
    # Positive historical progress is evidence, not a guaranteed recovery rate.
    # Avoid interpreting fitness deterioration as a spatial displacement.
    count = 2 if recovery_credit >= loss else 3
    return min(swarm_size, count)
# EVOLVE-BLOCK-END
