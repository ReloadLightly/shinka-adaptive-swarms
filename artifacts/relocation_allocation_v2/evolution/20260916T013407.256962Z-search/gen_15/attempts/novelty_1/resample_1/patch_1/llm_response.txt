<DESCRIPTION>
The current rule achieves mean error 3.16 but leaves substantial interval-end error in difficult cases while predominantly executing four relocations. This motivates testing diminishing returns from relocation against the value of continued ordinary PSO motion. The proposal scores every integer allocation using a smooth combination of contraction and loss exceeding recent improvement, replacing binary contraction thresholds. It is an untested hypothesis, not a measured improvement.

"""V2 allocation seed: relocate three particles after a detected change.
The fixed adapter controls radius, memory, velocity, integer validation and
count-to-fraction conversion. The numerical simulator is outside this program.
"""
# EVOLVE-BLOCK-START
def choose_relocation_count(observation: dict) -> int:
    """Balance diminishing relocation coverage against ordinary PSO motion."""
    import math
    swarm_size = int(observation["swarm_size"])
    if swarm_size <= 0:
        return 0
    radius = max(0.0, 2.0 * float(observation["default_radius"]))
    diameter = max(0.0, float(observation["swarm_diameter"]))
    previous_fitness = abs(float(observation["previous_best_fitness"]))
    loss = max(0.0, float(observation["fitness_drop"]))
    improvement = max(0.0, float(observation["recent_improvement"]))
    # Contracted swarms have less existing spatial coverage.
    spatial_scale = max(radius, diameter, 1e-12)
    scaled_radius = radius / spatial_scale
    scaled_diameter = diameter / spatial_scale
    contraction = scaled_radius**2 / max(
        scaled_radius**2 + scaled_diameter**2, 1e-12
    )
    # Treat loss as uncertain evidence, moderated by observed progress.
    unrecovered_loss = max(0.0, loss - improvement)
    fitness_scale = max(1.0, 0.05 * previous_fitness)
    pressure = unrecovered_loss / (
        unrecovered_loss + improvement + fitness_scale
    )
    relocation_weight = 1.5 + 3.0 * contraction * pressure
    best_count = 0
    best_utility = -math.inf
    for count in range(swarm_size + 1):
        utility = (
            relocation_weight * math.log1p(count)
            + math.log1p(swarm_size - count)
        )
        if utility > best_utility:
            best_utility = utility
            best_count = count
    return best_count
# EVOLVE-BLOCK-END
